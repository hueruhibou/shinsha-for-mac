# 真写 for Mac

Mac向けに操作を専用化した、ローカル保存型の写真反転ビューアです。

## 主な機能
- 写真・フォルダをドラッグ＆ドロップで追加（サブフォルダも対応ブラウザで展開）
- 写真／フォルダ選択ダイアログから一括読み込み
- IndexedDBへ端末内保存し、次回起動時に復元
- 追加順・古い順・ランダム順
- 一覧サムネイルの水平反転
- 大画面ビューア、水平反転、元画像の保存
- トラックパッド／マウスホイールで拡大縮小、拡大中のドラッグ移動
- キーボード：⌘O追加、←→切替、F反転、+/-拡大、0リセット、Esc閉じる
- タイトル「真写」からギャラリーへ戻る

## 公開
このフォルダの中身を独立したGitHubリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main / (root) を選択してください。HTTPSで公開されるとPWAとしてホーム画面／Dockへ追加できます。

## 保存について
写真はこのMacのブラウザのIndexedDBに保存され、サーバーには送信しません。Mac版専用のデータベース `shinsha-mac-library` を使用します。従来版のデータベース `shinsha-local-library` が同じブラウザ領域にある場合、初回起動時に写真をコピーして引き継ぎます。旧データは削除しません。

ブラウザのサイトデータ消去やストレージ管理により保存データが失われる可能性があります。元画像は別途バックアップしてください。

# 真写 PWA 試作

## 内容
- `index.html`: 真写のブラウザ版
- `manifest.webmanifest`: ホーム画面追加用の設定
- `sw.js`: アプリ本体のキャッシュ（オフライン起動用）
- アイコン画像一式

## 公開方法
PWAとしてインストールするにはHTTPSで配信する必要があります。
GitHub Pages / Cloudflare Pages などの静的ホスティングに、このフォルダの中身をアップロードしてください。

## iPhone
1. Safariで公開URLを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ

## Android
1. Chromeで公開URLを開く
2. メニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ

## 現時点の制限
- 写真の読み込みはブラウザのファイル選択経由です。
- この試作では、読み込んだ写真そのものをIndexedDBへ永続保存していません。ページを閉じた後も写真を保持する機能は次の開発段階です。
- iCloud写真のバックグラウンド自動取得は実装していません。WebブラウザではOS写真ライブラリとの連携に制限があります。
- フォルダ選択はブラウザ依存です。
